# Gender and Development integration

The lesson form includes **Integrate GAD in every session**, enabled by default, and an optional **GAD focus / classroom context** field under Curriculum Information. This applies to one through five selected sessions, including three-session plans.

The reference is [DepEd Order No. 32, s. 2017 — Gender-Responsive Basic Education Policy](https://www.deped.gov.ph/2017/06/29/do-32-s-2017-gender-responsive-basic-education-policy/). Its principles include gender equality, equity, sensitivity, non-discrimination, and human rights. These application features support teacher planning; they are not an official compliance assessment. No specific regional or division memorandum was supplied for this change.

## Using the feature

1. Enter the official competency, content standard, performance standard, and selected session count.
2. Leave GAD integration enabled. Optionally describe a relevant classroom context without identifying learners or disclosing sensitive personal information.
3. Generate and review the lesson plan. Each session includes a GAD entry in the existing Opportunities for integration cell, an actionable participation direction in Flow, a fair-assessment direction, and a teacher reflection question.
4. Generate the LAS and presentation from the reviewed lesson. They receive the same settings and the matching session's GAD content.
5. If GAD settings change after generation, regenerate the lesson before producing matching materials. The app clears outdated outputs when these settings change.

For residential measurement, a useful focus is: “Rotate measuring, drawing, computing, checking, and reporting roles. Show planning and maintaining residential spaces as shared responsibilities. Ensure all learners can use measuring tools and explain their computations.” Teachers should adapt the examples to the actual competency and learners.

## Behavior and boundaries

- The existing ILAW and LAS layouts, table labels, selected session count, and curriculum fields are preserved. No GAD column or template row is introduced.
- Prompt instructions request topic-specific integration. Normalization retains minimum actionable participation, assessment, and reflection directions even if an AI response omits them or concise output limits truncate them.
- The verified policy reference is included when GAD is enabled; it is an explicit exception to the usual teacher/upload-only references rule.
- LAS directions preserve participation opportunities. Presentation requests include each session's integration and reflection as well as instructions for stereotype-free visuals and examples.
- Disabling explicit GAD integration removes the added GAD instructions and automatic reference from new generation. Respectful, inclusive language remains required. Existing user-supplied GAD material is not stripped.
- No learner demographic fields, gender inference, compulsory disclosures, gender-based ability assumptions, or automatic policy-compliance claims are introduced.
- Teachers must validate actual subject examples, assessment fairness, participation opportunities, and generated slide imagery before classroom use. The application cannot establish implementation outcomes or policy compliance from prompt labels.

No database migration, new API key, or deployment environment variable is required. Existing clients that omit the new settings receive GAD enabled by default.
